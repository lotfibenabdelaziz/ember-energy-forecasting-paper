📉 Why does Ridge score well on evaluation but diverge in the forecast?
The MAPE shown for Ridge (and other ML models) is a 1-step-ahead walk-forward score: each test year is predicted using only one step from known history, so small extrapolation errors in exogenous features never get the chance to compound. The 2025–2030 forecast below is a 6-step recursive projection — each year's prediction feeds into the next year's inputs, so any instability (e.g. a lag/MA feature drifting outside its historical range) compounds exponentially over the horizon. This is exactly why a model can have the lowest test MAPE yet produce the least stable long-horizon curve — short-horizon accuracy and long-horizon stability are different properties, and only one of them is captured by MAPE.
